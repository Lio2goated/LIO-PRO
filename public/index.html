Find your exact specs on Windows

  1. Processor and RAM: press Win + Pause/Break, or open Settings › System › About.
  2. Graphics card: press Ctrl + Shift + Esc to open Task Manager › Performance › GPU.
  3. Storage type: in Task Manager › Performance, each disk shows "SSD" or "HDD".
  4. Refresh rate: Settings › System › Display › Advanced display.
